# Synthetic sample runs

Every file below this directory is intentionally fabricated for demonstration
and automated testing. The numbers describe no fabricated or production chip,
customer, employer, or tapeout. They were selected only to illustrate a
plausible convergence trend from an initial implementation to a closed sample
run.

Each run folder contains:

- `opensta_summary.rpt`: synthetic timing metrics;
- `openroad_summary.rpt`: synthetic physical and clock metrics; and
- `config.json`: synthetic run metadata used to label the comparison.

See [`DATA_PROVENANCE.md`](../DATA_PROVENANCE.md) for the complete provenance
and safe-use statement.
